# PalychGram

расширение для фаерфокса, докручивает веб-телеграм (`web.telegram.org`, k и z):
темы, блюр, мелкие удобства. всё хранится локально, никакой телеметрии и бэкендов.

сразу честно: серверное не трогаем. настоящий премиум, невидимый онлайн при
переписке, пересылка из закрытых каналов — это всё на сервере проверяется,
расширением не делается. тут только внешний вид и локальные твики.

## как поставить

1. `about:debugging#/runtime/this-firefox` → Load Temporary Add-on → `manifest.json`
2. открыть `web.telegram.org/k` или `/z`
3. настройки — по иконке в тулбаре или `about:addons` → Preferences

временное дополнение слетает при перезапуске фаерфокса, это нормально.
постоянная подпись — потом через AMO.

## что уже есть (0.2)

- 6 тем, цвет акцента, плотность, pills/chips папок, скругление аватарок
- блюр-режим (alt+shift+b), скрытие рекламы/похожих/сторис
- журнал удалённых (кнопка 🗑, только то что успел увидеть)
- секунды во времени, неокруглённые счётчики, бейдж ID чата
- снег, пауза медиа при сворачивании, перевод выделенного

## файлы

```
manifest.json
src/content/      — точка входа + css тем и блюра
src/lib/          — журнал удалённых, время, id, снег, автопауза, ghost-заглушки
src/background/   — контекстные меню
src/popup/        — быстрые тумблеры
src/options/      — все настройки + бекап
docs/             — FEATURES (что откуда), ROADMAP, CHANGELOG
```
