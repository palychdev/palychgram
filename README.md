# PalychGram

мод для веб-телеграма в виде расширения для Firefox и Chrome.
перекрашивает вебку, прячет лишнее, добавляет удобства которых нет в стоке.
работает поверх `web.telegram.org` (K, Z и A), ничего никуда не отправляет —
все настройки лежат локально.

что сразу понимать: серверную часть не трогаем и не обещаем.
премиум, невидимка в переписке, пересылка из закрытых каналов — всё это
решает сервер, а не клиент. здесь только то что реально работает:
внешний вид, приватность экрана и мелкие твики.

## как поставить

firefox: `about:debugging#/runtime/this-firefox` → Load Temporary Add-on →
`manifest.json` из корня. временное слетает при перезапуске, это нормально.

chrome: `python build.py` → распаковать зип с рабочего стола →
`chrome://extensions` → режим разработчика → «Загрузить распакованное
расширение» → выбрать папку. исходный манифест хром не ест (ему нужен
service worker), сборка правит это автоматом.

## что уже есть (0.3)

- 6 тем, цвет акцента, плотность, pills/chips папок, скругление аватарок
- размер шрифта, размер и скругление стикеров
- блюр-режим (alt+shift+b), опционально блюр текста, скрытие номеров
- скрытие рекламы/похожих/сторис, снятие copy-запретов
- журнал удалённых (кнопка 🗑, только то что успел увидеть)
- секунды во времени, неокруглённые счётчики, бейдж ID чата
- снег, пауза медиа при сворачивании, перевод выделенного

## файлы

```
manifest.json
src/content/      — точка входа + css тем и блюра
src/lib/          — журнал удалённых, время, id, снег, автопауза, ghost-заглушки
src/background/   — контекстные меню
src/popup/        — быстрые тумблеры
src/options/      — все настройки + бекап
docs/             — FEATURES (что откуда), ROADMAP, CHANGELOG
```
