# откуда что взято

смотрел exteragram (архивирован, там только визуал, госта и премиума нет),
nekogram и ayugram (десктоп + андроид). ниже что из их фич реально ложится
на расширение для вебки, а что нет.

## визуал — всё делается, уже в коде

темы, акцент, скругление аватарок, стили папок, блюр, снег, системные шрифты,
ширина чата, размер стикеров, секунды во времени, id/dc, скрытие рекламы и
похожих каналов, свой номер скрыть. чистый css/dom.

## удобство — делается

прочитать всё, правила скрытия по тексту/автору, свой перехват уведомлений,
доп пункты в меню (перевод, детали сообщения, запятая после меншена),
авто-пауза через visibility api, действия по даблклику.

## антиудаление — наполовину

текст кэшируем через mutationobserver в indexeddb, смотрим из панели.
медиа — только пока сообщение живо (blob). что не открывал — не восстановить.
секретных чатов в вебке вообще нет, так что мимо.

## гост — почти всё мимо, без иллюзий

- не слать "печатает" — одно поле в запросе, самое простое, но нужен инжект
  в page-контекст, из content-скрипта не достать. будет позже за флагом.
- подтверждение перед сторис — уже есть, это просто.
- отложенная отправка — очередь на клиенте, можно.
- не слать прочтение/онлайн — перехват mtproto в page-контексте, хрупко,
  ломается при каждом обновлении вебки. и всё равно сервер палит онлайн
  на любой отправке. в ближних планах нет.

## локальный премиум — только внешний вид

себе показать иконки/статус/оформление — можно. лимиты, скорость,
транскрибация — сервер, нет. в интерфейсе так и подписано что локально.

## точно не делаем

настоящий премиум, скрытие онлайна/прочтений без следов, форвард из
noforwards с авторством, секретные чаты в вебе, стилс сторис.
