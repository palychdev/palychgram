# PalychGram — карта фич (исследование ExteraGram / AyuGram / Nekogram)

Источники: `exteraSquad/exteraGram` (архивирован 28.01.2026, UI-форк без ghost/premium),
`Nekogram/Nekogram`, `AyuGram/AyuGramDesktop` + `AyuGram4A`, `docs.ayugram.one`.

Легенда:
- ✅ стабильно в Firefox content-script (DOM/CSS/storage)
- ⚠️ хрупко (page-инжект, перехват сети, ломается при обновлении WebK/WebZ)
- ❌ невозможно (сервер проверяет)

## 1. Визуал — делать первым (всё ✅)

Темы через CSS-переменные, акцент из обоев, скругление аватаров (`border-radius`),
стили папок (chips/pills, скрыть All Chats), центрирование заголовка, force blur,
снег (canvas-оверлей), системные шрифты, плотность/ширина чата, моно-шрифт,
размер/форма стикеров, hide time on stickers, секунды во времени, ID/DC пира,
скрытие sponsored/похожих каналов, скрытие своего номера (DOM).

## 2. Удобство (✅)

Message Shot (рендер сообщений в картинку), «прочитать всё», скрытие рекламы
по sender/тексту, перехват Notification API, доп. пункты контекстного меню
(перевод выделенного через внешний API, Copy Photo, Details: edit/forward даты,
размер, mime), запятая после меншена, auto-pause через Page Visibility API,
двойной клик-действия, seeking войсов.

## 3. Анти-удаление (✅ частично)

MutationObserver + IndexedDB журнал: текст легко, медиа — кэш blob пока сообщение
живо. То, что не было открыто — не восстановить. Бейджи edited/deleted — ✅.
Секретные чаты/TTL в Web отсутствуют — ❌.

## 4. Приватность / Ghost (⚠️/❌ — за флагом, выкл. по умолчанию)

- Typing-off (`sendMessageTypingAction` дроп) — ⚠️ самый лёгкий из группы.
- Confirm-before-story — ✅, делать сразу.
- Отложенная отправка (не светиться онлайном) — ✅ очередь на клиенте.
- Don't read / don't read stories / don't send online — ⚠️ только перехватом
  MTProto/WS в page-контексте, хрупко, плюс сервер ставит online на любой write
  (подтверждено доками AyuGram). Полной невидимки при активной переписке нет нигде.
- Streamer mode — ❌ в браузере; замена: Blur-privacy (CSS-класс по хоткею) — ✅.

## 5. «Локальный премиум» (визуал ✅ / настоящее ❌)

Можно локально: показать себе премиум-иконки/эмодзи-статус, снять copy/download
запреты в DOM, расширить recent стикеров в UI, authorised-look профиля
(цвета цитат, оформление). Обязательно подписать «только локально».

Нельзя: лимиты пинов/длина подписей/скорость/транскрибация/стикеры на сервере,
форвард из `noforwards` с авторством (только копирование контентом как новое
сообщение, без авторства), настоящий аплоад-буст.

## Порядок волн

1. Волна 1 (v0.1–v0.2): всё из п.1–3 + confirm-before-story + blur + снятие copy-запретов.
2. Волна 2: typing-off, отложенная отправка, локальный премиум-визуал, перевод.
3. Волна 3 (эксперимент): дроп `readHistory`/`updateStatus` за флагом
   «может сломаться при обновлении Telegram Web».
