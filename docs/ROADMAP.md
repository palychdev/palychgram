# PalychGram — roadmap

## v0.1 scaffold ✅ (закрыто)
Каркас MV2, темы-база, blur, журнал-скелет, честная карта фич.

## v0.2 wave-1 ✅ (этот релиз)
- 6 пресетов тем, акцент-свотчи, cozy-плотность, pills/chips папок
- Секунды во времени, неокруглённые счётчики, бейдж ID чата
- Журнал удалённых: FAB-панель, последние 100, очистка
- Снег, auto-pause, Alt+Shift+B блюр
- Popup + Options полностью, backup export/import
- Контекстные меню: перевод, копирование ссылки/ID

## v0.3 (след.)
- Message-menu: Copy Photo, Details (edit/forward даты, размер, mime)
- Перевод перед отправкой через настраиваемый API endpoint
- Отложенная отправка (send-delay UI в options + индикатор)
- Message Shot: рендер сообщений в картинку
- Скрин-тест на web.telegram.org/k и /z, список рабочих селекторов

## v0.4+ (эксперименты за флагом)
- typing-off через page-инжект (может ломаться при обновлении Web)
- Локальный премиум-визуал v2 (эмодзи-статус себе, цвета цитат)
- Кэш медиа для анти-удаления (blob пока сообщение живо)

## Никогда (серверное, не-цели)
Настоящий Premium/лимиты, скрытие online/read без следов при переписке,
форвард из noforwards с авторством, секретные чаты в Web, stories-stealth.
