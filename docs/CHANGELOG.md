# история

## 0.7.0
статистика сессии в попапе (ноды, минуты), экспорт видимых сообщений в txt.

## 0.6.0
шаблоны быстрых ответов (кнопка ⚡ в чате), заметки с автосохранением,
поиск по журналу удалённых.

## 0.5.0
свой css, автотема день/ночь, шрифт сообщений на выбор, широкий чат и
плотность реально применяются к пузырям.

## 0.4.0
реклама тихая по таймеру и выключена по дефолту, темы красят вебку через её
переменные, секция скорости (без анимаций, без блюра), даблклик-копи,
журнал скачивается в json.

## 0.3.1
переезд на mv3 чтобы хром грузил, фон на service worker, шим browser.*.

## 0.3.0
попап с секциями и версией, опции карточками, размер шрифта, размер и
скругление стикеров, скрытие номеров, блюр текста с раскрытием по ховеру.

## 0.2.0
6 тем, cozy-плотность, папки pills/chips, секунды, счётчики без округления,
бейдж id, журнал с панелью и очисткой, снег, автопауза, alt+shift+b,
попап со свотчами, опции с бекапом, перевод и копирование id в меню.

## 0.1.0
скелет: mv2, content/background/popup/options, базовые темы, блюр,
скрытие рекламы, подтверждение сторис, журнал-скелет.
